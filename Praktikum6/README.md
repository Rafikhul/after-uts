## Deskripsi Praktikum

Praktikum 6 membahas konsep **Abstraction (Abstraksi)** dalam Pemrograman Berorientasi Objek (OOP) menggunakan bahasa pemrograman Java.

Melalui praktikum ini, mahasiswa mempelajari cara menyederhanakan kompleksitas program dengan menyembunyikan detail implementasi dan hanya menampilkan bagian penting yang diperlukan.

## Materi yang Dipelajari

- Abstract Class dan Abstract Method.
- Interface dan implementasinya.
- Programming to an Interface.
- Polymorphism.
- Penerapan abstraction dalam sistem sederhana.
- Refactoring kode menggunakan prinsip abstraction.

## Tujuan Praktikum

1. Memahami konsep abstraction dalam Java.
2. Mampu membuat dan menggunakan abstract class serta interface.
3. Memahami penerapan interface pada beberapa class.
4. Menerapkan prinsip programming to an interface.
5. Mengembangkan program yang lebih modular dan mudah dipelihara.

## Teknologi yang Digunakan

- IDE: Visual Studio Code
